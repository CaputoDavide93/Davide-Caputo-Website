# 🔒 Security

This repository is a personal website: static HTML and CSS, self-hosted fonts and two small scripts: one runs search in the browser over a static index of pages, posts and projects, and one sets the colour theme from a value kept in the browser. There are no forms, no cookies, no server code and no third-party requests.

To report a problem, open a [private security advisory](https://github.com/CaputoDavide93/Davide-Caputo-Website/security/advisories/new) on this repository. Please don't open a public issue for a security problem.
