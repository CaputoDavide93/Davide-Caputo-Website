# Agent instructions

This repository follows Davide Caputo's house standards. The full spec is
[`reference/STYLE.md` in Repo-Standards](https://github.com/CaputoDavide93/Repo-Standards/blob/main/reference/STYLE.md)
(private). When this summary and the spec disagree, the spec wins.

## Rules that apply to every change

- **Documentation never lies.** Every command, flag, feature, count and badge must be true of the code. Verify before writing; delete what you can't verify. No hand-typed counts that can drift.
- **Commits:** conventional (`fix:`, `feat:`, `docs:`, `refactor:`, `ci:`, `chore:`), authored by the repo owner. No co-author trailers, session ids or "generated by" lines in commits, PRs, issues or comments.
- **Never** force-push the default branch, commit secrets, or change runtime identifiers (env var names, container/image names, bundle IDs, entity IDs, public URLs) as a side effect.
- **Secrets:** never put a secret, key, token, IP address, private host name, family name or personal e-mail in `AGENTS.md`, docs or code. The one public contact address is the single exception. `.gitignore` carries the secrets block from `assets/gitignore-secrets.txt`.
- Run the repo's own checks (tests, lint, build, `python3 tools/gen_diagram.py --check`) before and after; anything green before stays green.

## README

- Centered header: one emoji H1 (the same emoji as the GitHub description), a **bold** one-line tagline, flat shields.io badges (tech → platform → license → live CI; no `style=`), then `---`.
- Emoji `##` headings in the canonical order, `---` between sections, features as an emoji-lead table, a repo tree in a ` ```text ` block that matches `git ls-files`.
- `## 🗺️ Architecture` opens with the house-kit diagram: `tools/gen_diagram.py` writes `docs/assets/architecture-{light,dark}.svg`, embedded with `<picture>` (dark `<source>` + light `<img width="100%">` + a one-sentence alt). No Mermaid for architecture, no ASCII boxes.
- Screenshots live in `docs/assets/screenshots/<screen>-{light,dark}.png`; public repos use demo data only.
- The README ends with `---` and then exactly:
  `<p align="center"><sub>Made with ❤️ by <a href="https://github.com/CaputoDavide93">Davide Caputo</a></sub></p>`
  (translated only when the README body is in another language). No star request, no extra lines.

## Layout and naming

- Directories `lowercase-kebab`; docs `docs/lowercase-kebab.md`; shell scripts `kebab-case.sh`; Python `snake_case`; TS/JS modules `kebab-case`, React components `PascalCase.tsx`. Toolchain rules win (Xcode targets, HA `custom_components/<domain>`, Python import names, Kotlin packages, ESPHome/HA `.yaml`).
- Root holds only README, LICENSE, SECURITY, CONTRIBUTING, CHANGELOG, AGENTS (`.md`) plus config files. `AGENTS.md` is the single agent index: no vendor-specific agent file (`CLAUDE.md`, `GEMINI.md`, `.cursorrules`, `.github/copilot-instructions.md`) and no pointer file. Code in `src/` (or the toolchain's dir), tests in `tests/`, `scripts/` for things that touch live systems, `tools/` for repo generators, `config/` for samples, docs in `docs/` with `docs/README.md` once there are more than five, superseded material in `docs/archive/YYYY/`.
- One `.env.example` with every variable the code reads (obviously fake placeholders). Examples are `<name>.example.<ext>`.

This repository is the public personal website of Davide Caputo, served by GitHub Pages from `main` at the root for `davidecaputo.com`. It is the personal site only: no house services, no Home Assistant, no tunnel.

## Commands

- Preview: `python3 -m http.server 8000`, then open `http://localhost:8000/`.
- Rules: `python3 tests/check_site.py`.
- Diagram check: `python3 tools/gen_diagram.py --check` (write with `python3 tools/gen_diagram.py`).

## Layout

- `index.html` is the whole page; `assets/site.css`, `assets/site.js`, `assets/favicon.svg` and `assets/fonts/` (Host Grotesk and JetBrains Mono, self-hosted).
- `tests/check_site.py` pins the owner's rules. `tools/gen_diagram.py` writes `docs/assets/architecture-{light,dark}.svg`.
- `.nojekyll` keeps Pages from running Jekyll.

## Conventions

- **No personal contact details on the page** (decided 2026-11-26): no phone number, e-mail address, `mailto:` or `tel:` link, home town or citizenship. Contact is through LinkedIn. `tests/check_site.py` enforces it; never weaken the list to make a change pass.
- Facts come from the owner's CV and public GitHub repositories only. Nothing is invented: no figures, clients, quotes or awards. A new employer, date or certificate comes from the owner.
- One heading per idea, plain words, sentence case. One accent colour, flat grounds, no photographs of people unless the owner supplies them. No cookies, analytics or third-party requests; fonts stay self-hosted.
- Pull requests only; the gate is the two commands above plus a look at 1440, 1024, 768 and 390 px.

## Do not touch

- `docs/assets/architecture-*.svg` by hand: the generator rewrites them.
- The domain `davidecaputo.com` and the `CNAME` file once Pages is enabled: they are the site's public address.

## Secrets

- Nothing secret belongs here. No keys, tokens, IP addresses, private host names or personal e-mail.
